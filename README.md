# GutDiary Android

Локальное Android-приложение на базе встроенного Android WebView. Данные дневника хранятся в локальном хранилище WebView на устройстве. Для работы дневника интернет не требуется.

## Возможности
- дневник питания и FODMAP-оценка;
- симптомы, интенсивность, задержка реакции, шкала Бристоля;
- обзор и недельный график;
- удаление ошибочных записей;
- экспорт CSV через системное хранилище Android;
- печать через Android Print Framework.

## Сборка APK
Откройте проект в Android Studio либо запустите `gradle assembleDebug` на машине с Android SDK Platform 35 и JDK 17. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions workflow `.github/workflows/build-apk.yml` автоматически собирает APK при push в `main`. Артефакт прикрепляется к успешному запуску workflow.

## Важно
Это личный дневник, не медицинский диагностический инструмент. FODMAP-каталог — справочный ориентир, не подтверждение безопасной порции. Персонализацию low-FODMAP лучше проводить с квалифицированным специалистом.
